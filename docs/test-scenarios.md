# エージェントA テストシナリオ

opencrab実装済み機能の網羅的テスト計画。  
テスト環境: `#kairo-test` チャンネル / エージェントABot (ID: 234567890123456789)

---

## フェーズ1: 基本動作（Discord Gateway）

### T-01: 自己メッセージ無視
- **目的**: エージェントA自身の発言に反応しないこと
- **手順**: エージェントAが何か発言した後、ループが発生しないことを観察
- **期待値**: エージェントAの発言に対してエージェントAが反応しない
- **実装**: `discord.rs` の `self_user_id` チェック
- **ステータス**: ✅ 2026-03-21 確認済み

### T-02: Typing Indicator
- **目的**: 応答処理中にタイピング表示が出ること
- **手順**: `#kairo-test` に質問を送る
- **期待値**: エージェントAのアイコンにタイピング表示が出てから返答が来る
- **実装**: `message_loop.rs` の `start_typing()`

### T-03: 未登録チャンネルの無視
- **目的**: DBに登録されていないチャンネルのメッセージを無視する
- **手順**: エージェントAが読まない予定のチャンネルに話しかける
- **期待値**: エージェントAが反応しない
- **実装**: `is_channel_readable()` チェック

---

## フェーズ2: ユーザーホワイトリスト（Trusted Users）

### T-04: オーナーはDMで常に許可
- **目的**: `owner_discord_id` ユーザーはホワイトリスト外でも許可される
- **手順**: owner (123456789012345678) からエージェントAにDM送信
- **期待値**: 応答が返る

### T-05: 未登録ユーザーのDM拒否
- **目的**: ホワイトリストが空でない場合、未登録ユーザーのDMを無視
- **手順**:
  1. APIでホワイトリストにダミーユーザーを1人追加
  2. 別のユーザーからDM送信
- **期待値**: 応答なし (ログに "Ignoring DM from non-whitelisted user" が出る)
- **実装**: `trusted_users.rs` API + `message_loop.rs`

### T-06: ホワイトリスト追加後のDM許可
- **目的**: API経由で登録したユーザーはDM可能
- **手順**:
  1. API `POST /api/agents/{id}/trusted-users` でユーザー登録
  2. 登録したユーザーからDM送信
- **期待値**: 応答が返る
- **API**: `POST /api/agents/crab/trusted-users`

---

## フェーズ3: execute_shell（シェルツール）

### T-07: 許可コマンドの実行
- **目的**: ホワイトリスト内のコマンドが正常実行される
- **手順**: エージェントAに「`ls /tmp` を実行して」と指示
- **期待値**: コマンド出力が返ってくる
- **前提**: `tools.toml` で `ls` が `allowed_commands` に登録されていること

### T-08: 禁止コマンドの拒否
- **目的**: ホワイトリスト外コマンドは実行できない
- **手順**: エージェントAに「`rm -rf /tmp/test` を実行して」と指示
- **期待値**: "Command 'rm' is not in the allowed list" エラーが返る
- **実装**: `shell.rs` の `effective_commands()` チェック

### T-09: Owner限定コマンドの権限チェック
- **目的**: `permission = "owner"` のコマンドはAgent/CoAgentが実行できない
- **手順**: AgentがOwner限定コマンドを呼び出す
- **期待値**: 権限エラーが返る
- **実装**: `CallerIdentity::Agent` vs `CommandPermission::Owner`

### T-10: ファイル作成（Workspace経由）
- **目的**: `ws_write` でエージェントワークスペースにファイル作成
- **手順**: エージェントAに「`hello3.txt` に "Hello from Kairo!" と書いて」と指示
- **期待値**: ファイルが `data/agents/crab/workspace/hello3.txt` に作られる

### T-11: ファイル読み取り（Workspace経由）
- **目的**: `ws_read` でワークスペースのファイルを読める
- **手順**: T-10で作ったファイルを読ませる
- **期待値**: "Hello from Kairo!" が返ってくる

### T-12: パストラバーサル防止
- **目的**: ワークスペース外のファイルにアクセスできない
- **手順**: エージェントAに `../../etc/passwd` を読むよう指示
- **期待値**: セキュリティエラーが返る
- **実装**: ワークスペースのサンドボックス保護

## フェーズ4: ホットリロード（Hot-Reload）

### T-13: tools.toml変更の即時反映
- **目的**: `config/tools.toml` 変更がサーバー再起動なしで反映される
- **手順**:
  1. エージェントAが実行できないコマンドを確認（例: `date`）
  2. `tools.toml` に `date` を追加
  3. 数秒後に再度 `date` を実行するよう指示
- **期待値**: 再起動なしで `date` コマンドが実行される
- **実装**: `notify_debouncer_mini` による config watch

---

## フェーズ5: Co-Agent管理

### T-14: Co-Agent登録
- **目的**: API経由でco-agentを登録できる
- **手順**: `POST /api/agents/crab/co-agents` でエージェントCを登録
- **期待値**: 登録成功

### T-15: Co-AgentからのDiscord指示
- **目的**: 登録されたco-agentからの指示が通る
- **手順**: エージェントCが `#kairo-test` でエージェントAに指示を送る
- **期待値**: エージェントAが実行して結果を返す
- **実装**: `co_agents.rs` + メッセージ処理での caller 判定

### T-16: 未登録エージェントの拒否
- **目的**: co-agentとして未登録のエージェントからの権限要求を拒否
- **期待値**: 一般ユーザーとして処理される（Owner/CoAgent権限なし）

---

## フェーズ6: エラー耐性

### T-17: 長いメッセージの切り捨て
- **目的**: `max_output_bytes` を超える出力が切り捨てられる
- **手順**: 大量の出力を返すコマンドを実行させる
- **期待値**: 出力が切り捨てられ `truncated: true` が返る

### T-18: タイムアウト処理
- **目的**: `timeout_secs` を超えるコマンドが適切に終了される
- **手順**: `sleep 60` を許可リストに追加して実行させる
- **期待値**: タイムアウトエラーが返る（デフォルト30秒）

### T-19: 空メッセージの無視
- **目的**: 空テキストのメッセージは処理しない
- **期待値**: 反応なし
- **実装**: `message_loop.rs` の `!t.is_empty()` チェック

---

## フェーズ7: メモリ・学習

### T-20: 会話履歴の記憶
- **目的**: 以前の会話内容を覚えているか
- **手順**:
  1. 「私の名前はエージェントAテストユーザーです」と伝える
  2. 別の会話で「私の名前は？」と聞く
- **期待値**: 以前の情報を参照した回答が返る

### T-21: SearchMyHistory
- **目的**: `search_my_history` アクションが動作する
- **手順**: エージェントAに「過去の会話から "テスト" に関する話を検索して」と指示
- **期待値**: 関連する過去の会話が返ってくる
